# Security policy

Snowball Tracker is an offline desktop app. It stores data only in a local JSON file and makes no network requests.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's
[private vulnerability reporting](https://github.com/Ranzz02/snowball-tracker/security/advisories/new)
instead. You should get a reply within a week.

Only the latest release receives fixes.
