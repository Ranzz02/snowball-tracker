## 1.0.0 (2026-10-22)

### Features

- Runs with a hunter, boss checklist and a map picker that shows the targets left on each map
- Raid editor for boss kills, PMC kills, team kills, deaths, extracts, and one-click or custom bonuses and penalties, with a breakdown for each helper
- Hunter death ends the run
- Ledger with settle-up, payment history and copy-for-Discord summaries
- Local JSON storage with migration from older saves, plus backup export and import
- Tarkov-style dark UI with boss portraits
